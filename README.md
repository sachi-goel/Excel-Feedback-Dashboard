# Excel Feedback Dashboard

## Overview
This project is an **Excel dashboard** to analyze feedback data easily. It helps track key metrics and understand trends in a simple way.

## Features
- Interactive charts and tables
- KPI cards for quick insights
- Data filtering using slicers
- Detailed table for each feedback/transaction

## Tools Used
- Microsoft Excel
- Pivot Tables & Charts
- Formulas (SUM, AVERAGE, IF)
- Data cleaning and dashboard design

## How to Use
1. Open the Excel file.
2. Go to the Dashboard sheet to see charts and KPIs.
3. Use the slicers to filter data.
4. Check the Data sheet for detailed records.

## Learning
- Learned how to create dashboards in Excel
- Worked with charts, pivot tables, and formulas
- Turned raw data into useful insights
